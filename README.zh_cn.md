# 关于
Create: Occult Engineering 是一个将 Create 模组与 Occultism 模组相结合的模组，使你能够自动化处理
秘术仪式和异界活动。

# 入门指南
首先用灵魂词典（Dictionary of Spirits）和齿轮（Cogwheel）来合成一本灵魂百科（Encyclopedia of Souls）。

剩下的内容可以在书中发现，或通过 JEI 浏览配方。

此外，所有“秘术机械”（Occult Machinery）都通过 Create 的 Ponder 系统提供说明。

缺少文档被视为一个 Bug，因此如果有任何不理解的地方，请通过 Discord 或 GitHub 报告。

# 主要特性

## 精灵火焰自动化

在封闭风扇（Encased Fan）前放置灵火（Spiritfire）或灵火营火（Spirit Campfire），即可实现自动化！

## 仪式自动化

使用机械舱室（Mechanical Chamber）自动化任何不需要牺牲或外部物品使用的仪式。

机械臂（Mechanical Arm）是向机械舱室插入书籍的最佳方式，它会像往常一样使用周围祭品碗（Sacrificial Bowls）中的物品。

## 粉碎自动化

使用机械粉碎机（Mechanical Pulverizer）将物品自动粉碎成粉末。它可以替代 Occultism 的粉碎实体，
从而实现所有粉末的自动化。

## 元素流传送器（Phlogiports）

元素流传送器可根据地址无线传输包裹。欲了解更多信息，请在游戏中使用 Ponder 系统。

## 异界探测器

当最近的玩家拥有异界视野（无论是护目镜还是“第三只眼”药水效果）时，异界探测器会输出红石信号。

从探测器取比较器输出，即可获得最近拥有异界视野的玩家的距离！

## 精灵溶液（Spirit Solution）

通过加热将恶魔之梦果（Demon's Dream Fruit）与水混合，或粉碎恶魔之梦种子（Demon's Dream Seeds）即可制成精灵溶液。
精灵溶液用于装订书籍，以替代使用灵魂词典。未来还会用于其他有用的用途。

# 支持的版本

本模组遵循 Create 的支持版本，目前兼容 Minecraft 1.20.1 与 1.21.1。

Create 版本必须 ≥ 6.0.8。

# 部分开发的功能

这些功能被视为部分开发，因为它们有一定功能，但尚未完全完成，
也不一定具有逻辑上的进阶内容。

## 新仪式

铜、锌与黄铜粉笔可以像 Occultism 的普通粉笔一样被合成并绘制在地面上，
并用于新的仪式。

## 新灵体

### Púca（普卡）

Púca 是一个新增灵体，加入到现有的 4 个基础灵体中。未来它将用于 Create 模组的辅助实体，
类似于 Occultism 模组中的伐木工灵体。
