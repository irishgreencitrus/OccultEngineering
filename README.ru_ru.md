# О моде
Create: Occult Engineering — это мод, который интегрирует Create с Occultism, позволяя автоматизировать оккультные ритуалы и иные потусторонние процессы.

# Начало игры
Начните, создав Энциклопедию Душ из Словаря Духов и Зубчатого колеса.

Остальное можно узнать из книги или изучая рецепты в JEI.

Кроме того, вся «Оккультная техника» задокументирована через систему Ponder мода Create.

Отсутствие документации считается ошибкой, поэтому, если вы чего-то не понимаете, сообщайте об этом через Discord или GitHub.

# Основные возможности

## Автоматизация Spiritfire

Разместите Spiritfire или Духовный костёр перед Закрытым вентилятором, чтобы автоматизировать процесс!

## Автоматизация ритуалов

Автоматизируйте любые ритуалы (которые не требуют жертвоприношения или использования внешних предметов) с помощью Механической Камеры.

Механическая Рука — лучший способ помещать книги в Механическую Камеру; она использует предметы в Жертвенных Чашах вокруг неё как обычно.

## Автоматизация дробления

Автоматизируйте дробление в пыль с помощью Механического Измельчителя. Это может использоваться вместо дробящих сущностей из Occultism для автоматизации всех видов пыли.

## Флогипорты

Флогипорты позволяют беспроводным образом перемещать посылки по их адресу. Для дополнительной информации используйте систему Ponder в игре.

## Детектор Иного Мира

Детектор иного мира выдаёт сигнал красного камня, если ближайший игрок имеет зрение иного мира (очки или эффект зелья «третьего глаза»).

Снимите выход компаратора, чтобы получить расстояние до ближайшего игрока со зрением иного мира!

## Раствор Духов

Создаётся либо перемешиванием Плода Демонского Сна с водой при нагреве, либо дроблением Семян Демонского Сна. Раствор Духов используется для переплёта книг вместо крафта со Словарём Духов. В будущем он будет использоваться и для других полезных вещей.

# Поддерживаемые версии

Этот мод следует поддерживаемым версиям Create, то есть на данный момент совместим с Minecraft 1.20.1 и 1.21.1.

Версия Create должна быть >= 6.0.8.

# Частично разработанные функции

Эти функции считаются частично разработанными, поскольку у них есть некоторая функциональность, но они ещё не завершены и могут не иметь логической прогрессии.

## Новые ритуалы

Мелок из меди, цинка и латуни можно создать и рисовать им на земле так же, как обычным мелком из Occultism; он используется для новых ритуалов.

## Новые духи

### Пука

Пука — это новый дух, добавляемый к четырём существующим базовым духам. В будущем он будет использоваться для созданий-помощников в стиле мода Create, похожих на лесорубов из Occultism.
