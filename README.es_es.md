# Acerca de
Create: Occult Engineering es un mod que integra el mod Create con Occultism, permitiéndote automatizar los rituales
ocultos y actividades de otro mundo.

# Primeros pasos
Empieza fabricando una Enciclopedia de Almas a partir de un Diccionario de Espíritus y una Rueda dentada (Cogwheel).

El resto puede descubrirse dentro del libro o leyendo las recetas en JEI.

Además de esto, toda la “Maquinaria Oculta” está documentada mediante el sistema Ponder de Create.

La falta de documentación se considera un error, así que por favor informa de cualquier cosa que no entiendas a través de Discord o GitHub.

# Características principales

## Automatización con Fuego Espiritual

¡Coloca un Fuego Espiritual o una Hoguera Espiritual delante de un Ventilador Encastrado para automatizar el proceso!

## Automatización de rituales

Automatiza cualquier ritual (que no requiera un sacrificio o el uso de un objeto externo) usando la Cámara Mecánica.

El Brazo Mecánico es la mejor manera de insertar libros en la Cámara Mecánica, y utiliza los objetos en los Cuencos
Sacrificiales
alrededor como de costumbre.

## Automatización de trituración

Automatiza la trituración en polvo usando el Pulverizador Mecánico. Esto puede utilizarse en lugar de las entidades trituradoras de Occultism para automatizar todos los polvos.

## Flogipuertos (Phlogiports)

Los Flogipuertos pueden usarse para transferir paquetes de forma inalámbrica según su dirección. Para más información, usa el sistema Ponder en el juego.

## Detector de Otro Mundo

El detector de otro mundo emite una señal de Redstone si el jugador más cercano tiene la visión de otro mundo
(ya sea por las gafas o por el efecto de poción del tercer ojo).

¡Saca una salida de comparador de él para obtener la distancia al jugador más cercano con la visión de otro mundo!

## Disolución Espiritual

Fabricada mezclando Fruta del Sueño del Demonio con agua mientras está calentada, o triturando Semillas del Sueño del Demonio,
la Disolución Espiritual se usa para encuadernar libros en lugar de fabricar con un Diccionario de Espíritus. En el futuro se usará para otras cosas útiles.

# Versiones compatibles

Este mod sigue las versiones compatibles de Create, lo que significa que actualmente es compatible con Minecraft 1.20.1 y 1.21.1.

La versión de Create debe ser >= 6.0.8.

# Paridad de características

Intento mantener tanto 1.20.1 como 1.21.1 con paridad de características, pero si olvido algo, por favor repórtalo a través de Discord o GitHub.

# Características parcialmente desarrolladas

Estas características se consideran parcialmente desarrolladas porque existe algo de funcionalidad, pero no están completas
ni necesariamente tienen una progresión lógica.

## Nuevos rituales

La tiza de Cobre, Zinc y Latón puede fabricarse y dibujarse en el suelo como la tiza normal de Occultism,
y se usa para nuevos rituales.

## Nuevos espíritus

### El Púca

El Púca es un nuevo espíritu que se añade a los 4 espíritus base existentes. En el futuro se utilizará para entidades auxiliares del mod Create, de forma similar a los leñadores del mod Occultism.
