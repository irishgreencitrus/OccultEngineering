# À propos
Create: Occult Engineering est un mod qui intègre le mod Create avec Occultism, permettant d'automatiser les rituels occultes et les activités d’un autre monde.

# Appel à tous les traducteurs !
Malheureusement, je n’ai pas les compétences nécessaires pour traduire ce mod dans toutes les langues, donc j’ai besoin de votre aide !

Tout le texte de ce mod est pré-traduit via une IA, mais si vous trouvez quelque chose qui sonne un peu étrange, n’hésitez pas à contribuer sur Crowdin !

# Premiers pas
Commencez par fabriquer une Encyclopédie des Âmes à partir d’un Dictionnaire des Esprits et d’une Roue Dentée (Cogwheel).

Le reste peut être découvert dans le livre ou en consultant les recettes via JEI.

De plus, toutes les « Machines Occultes » sont documentées via le système Ponder de Create.

Un manque de documentation est considéré comme un bug, donc merci de signaler tout ce que vous ne comprenez pas sur Discord ou GitHub.

# Fonctionnalités principales

## Automatisation du Feu Spirituel

Placez un Feu Spirituel ou un Feu de Camp Spirituel devant un Ventilateur Caréné (Encased Fan) pour automatiser le processus !

## Automatisation des Rituels

Automatisez n’importe quel rituel (qui ne nécessite ni sacrifice ni utilisation d’objet externe) grâce à la Chambre Mécanique.

Le Bras Mécanique (Mechanical Arm) est le meilleur moyen d’insérer les livres dans la Chambre Mécanique, et il utilise les objets placés dans les Bols Sacrificiels autour d’elle comme d’habitude.

## Automatisation du Broyage

Automatisez le broyage en poussière grâce au Pulvériseur Mécanique. Celui-ci peut être utilisé à la place des entités de broyage d’Occultism pour automatiser toutes les poudres.

## Phlogiports

Les Phlogiports permettent de transférer des paquets sans fil en fonction de leur adresse. Pour plus d’informations, utilisez le système Ponder en jeu.

## Détecteur d’Autremonde

Le détecteur d’autremonde émet un signal de Redstone si le joueur le plus proche possède la vision de l’autremonde (soit via les lunettes, soit via l’effet de potion « troisième œil »).

Connectez-y un comparateur pour obtenir la distance jusqu’au joueur le plus proche possédant cette vision !

## Solution Spirituelle

Fabriquée soit en mélangeant des Fruits du Rêve du Démon avec de l’eau chauffée, soit en broyant des Graines du Rêve du Démon, la Solution Spirituelle est utilisée pour relier les livres à la place du Dictionnaire des Esprits. À l’avenir, elle servira pour d’autres usages utiles.

# Versions prises en charge

Ce mod suit les versions prises en charge par Create, ce qui signifie qu’il est actuellement compatible avec Minecraft 1.20.1 et 1.21.1.

La version de Create doit être ≥ 6.0.8.

# Parité des fonctionnalités

J’essaie de maintenir la parité des fonctionnalités entre les versions 1.20.1 et 1.21.1, mais si j’oublie quelque chose, merci de le signaler sur Discord ou GitHub.

# Fonctionnalités partiellement développées

Ces fonctionnalités sont considérées comme partiellement développées, car elles possèdent une certaine fonctionnalité mais ne sont pas totalement complètes, et n’ont pas nécessairement de progression logique.

## Nouveaux Rituels

Les craies de Cuivre, Zinc et Laiton peuvent être fabriquées et dessinées au sol comme les craies classiques d’Occultism, et sont utilisées pour de nouveaux rituels.

## Nouveaux Esprits

### Le Púca

Le Púca est un nouvel esprit ajouté aux 4 esprits de base existants. À l’avenir, il sera utilisé pour des entités d’assistance du mod Create, à l’image des bûcherons du mod Occultism.
